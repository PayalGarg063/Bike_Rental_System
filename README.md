# 🏍️ Bike Rental System

> **Database Management System Project**  
> A MySQL-based bike rental database for managing customers, bikes, rentals, and payments.  
> Includes **4 tables, 31 sample records, and 20 SQL queries** for retrieving and analyzing rental data.

---

## ❓ Why This Project

Managing a bike rental system requires maintaining information about **customers, bikes, rentals, and payments** in an organized database.

**This project implements a relational database for storing and retrieving bike rental information using MySQL.**

### Key Features:

* 👤 **Customer Management**: Stores customer details including customer ID, name, and phone number.

* 🏍️ **Bike Management**: Stores bike model, type, rent per day, and availability status.

* 📅 **Rental Management**: Records rental details including customer, bike, rent date, and return date.

* 💳 **Payment Management**: Stores payment information linked to rental records.

* 🔎 **SQL Querying**: Includes **20 SQL queries** for retrieving and analyzing rental data using JOINs, GROUP BY, aggregate functions, subqueries, and filtering.

* 🔄 **Transactions**: Includes SQL operations using **COMMIT and ROLLBACK**.


The SQL file creates the database:
