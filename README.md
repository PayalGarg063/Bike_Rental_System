# Bike Rental System – DBMS Project

## Overview

This project implements a **Bike Rental System** using **MySQL**. The database stores customer, bike, rental, and payment information and uses SQL queries to retrieve and analyze rental data.

## Database Structure

The database contains **4 tables**:

### 1. Customers

Stores customer ID, name, and phone number.

### 2. Bikes

Stores bike ID, model, type, daily rent, and availability status.

### 3. Rentals

Stores rental details and connects customers with bikes.

### 4. Payments

Stores payment details linked to rentals.

## SQL Queries

The project includes **20 SQL queries** covering:

1. Retrieve all available bikes
2. Find ongoing rentals
3. Find the total number of bikes
4. Display customer name, bike model, and rental date
5. Calculate total revenue generated by each bike
6. Find the total amount spent by each customer
7. Count how many times each bike has been rented
8. Find the most rented bike
9. Find bikes that have never been rented
10. Find customers who have never rented a bike
11. Find bikes whose rent per day is higher than average
12. Find rentals without a recorded payment
13. Find the customer who has spent the maximum amount
14. Find rentals where total payment is greater than average payment
15. Find rentals that lasted more than 2 days
16. Find the bike currently rented for the longest time
17. Perform an UPDATE with ROLLBACK
18. Perform an UPDATE with COMMIT
19. Check database grants
20. Check current user information

## How to Run

1. Open **MySQL Workbench** or another MySQL client.
2. Open `bike_rental_system.sql`.
3. Run the script from top to bottom.
4. The database `project1` and its 4 tables will be created.
5. The sample data will be inserted.
6. Run the queries individually to view their results.
